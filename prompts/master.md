## Binding constraints — do not violate these without changing DECISIONS.md first

1. **Never hand-write OpenDRIVE.** `netconvert --opendrive-output` is the only
   OpenDRIVE writer in this project (ADR-003).
2. **netconvert plain XML is the editable substrate.** All model edits land on
   `plain.edg.xml`; every consumer is regenerated by one `netconvert` call
   (ADR-004).
3. **AI never mutates the model.** It writes observations with a confidence and
   `status: REVIEW`. A human accepts or rejects (ADR-002).
4. **Observations are immutable.** Rejecting sets status; it never deletes.
5. **Lane closure is a rerouter additional-file**, not a network edit (ADR-006).
   Baseline and closure share network, routes and seed set.
6. **Core runtime dependencies are frozen at:** `fastapi uvicorn pydantic
   requests lxml numpy pillow`. Do **not** add geopandas, gdal, rasterio,
   networkx or osmnx to the core sidecar (ADR-011). `torch`/`transformers`
   belong to the separate vision sidecar only (ADR-007).
7. **Any AI output with real-world geometry must come from georeferenced
   imagery.** Anything else is tagged `geometry_kind: "image_space"` (ADR-005).
8. **Never hardcode a metric.** Every number comes from parsing SUMO output.
9. **Never fail silently.** If something cannot be done, say so in the UI.
10. **No 3D view** (ADR-012). **No pothole detection** (ADR-013).

## Working rules

- Prefer editing the existing modules in `core/` and `vision/` over writing new
  ones. They are already unit-tested by `scripts/selftest.py`.
- After any change to `core/` or `vision/`, run `python scripts/selftest.py`.
- At the end of every working session, run `python scripts/run_benchmark.py`
  and update `context/CURRENT_STATE.md`.
- Do not claim a phase is complete until its GATE in `EXECUTION_PLAN.md` passes.
- If you hit a genuine blocker, stop and say so rather than building a
  workaround that hides it.

of a judge is worth more than cleverness.
